# Analytical Casework Lab

A public repository for reproducible, learner-authored analytical casework.

## Cases

- [C01 - Football Event Intelligence](cases/C01-football-event-intelligence/README.md) - evaluates whether Chelsea FCW's high regains and post-regain attacking outcomes were genuinely distinctive relative to Manchester City WFC and Arsenal WFC in the 2023/24 FA Women's Super League.

## Repository principles

- Only learner-safe, publication-safe material is committed.
- Data provenance and reproduction instructions live inside each case README.
- Raw assessment data, evaluator-only material, hidden checks, caches and local checkpoints are not committed.
- Material AI assistance is disclosed in each case's `AI_USE.md`.

This repository records reproducible case work and assessed submission states; project-management status remains outside GitHub.
