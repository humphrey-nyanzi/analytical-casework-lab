# LP-001 - Operational Definitions & Edge Cases

**Type:** Micro-lab

**Status:** Ready, not started

**Feeds into:** OR-C02, MC-C02-01, and C02

## Objective

Build the ability to turn an ambiguous sports concept into a plain-language definition, a measurable rule, and a tested implementation.

## Mastery target

Explain -> implement -> diagnose.

By completion, this micro-lab should show that the learner can:

1. define an ambiguous sports concept in plain language;
2. convert it into a measurable rule;
3. specify material edge cases;
4. implement the rule against a small dataset; and
5. diagnose at least one intentionally ambiguous case.

## Evidence to add when the work starts

- the selected concept and analytical question;
- data provenance and a minimal learner-safe sample;
- the operational definition and edge-case rules;
- the implementation artifact;
- a visible check or diagnosis result;
- a short reflection on what can be explained without AI; and
- any material AI-use disclosure.
